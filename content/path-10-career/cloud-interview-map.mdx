Hands-on labs in DE101 run on **Docker** and your **VPS**. Employers still ask cloud questions—this page is a **map**, not a billable lab.

| Theme | AWS (words) | GCP (words) | Azure (words) |
|-------|-------------|-------------|---------------|
| Object storage | S3 | Cloud Storage | Blob Storage |
| IAM | IAM roles/policies | Cloud IAM | Entra ID + RBAC |
| Warehouse | Redshift / Spectrum | BigQuery | Synapse |
| Orchestration | MWAA / Step Functions | Cloud Composer | Data Factory |

**Study method:** Pick one row per week. Write how MinIO or Postgres in our labs **resembles** the cloud service (API shape, not vendor lock-in).
