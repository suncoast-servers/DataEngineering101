## Summary

1. Provision a Linux VPS (2 GB RAM minimum for `core`; 4 GB for capstone batch).
2. Install Docker Engine and the Compose plugin.
3. Clone this repo, copy `.env`, restrict ports with **UFW** (22, 443 only; do not expose Postgres to the public internet).
4. Use SSH tunnel or VPN for admin UIs when learning.
