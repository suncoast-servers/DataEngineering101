## Why

Data engineers live in files: SQL, Python, YAML, and config. An **IDE** (integrated development environment) is where you edit, run, and debug that work.

## Concept

- **VS Code** — free, huge extension ecosystem; common in industry.
- **Cursor** — VS Code–compatible editor with AI built in; many engineers use it daily.
- **Terminal** inside the editor runs Git, Docker, and Python without context-switching.

## Do

1. Install [VS Code](https://code.visualstudio.com/) or [Cursor](https://cursor.com/).
2. Install the **Python** and **Docker** extensions (either editor).
3. Open the cloned `DataEngineering101` folder as your workspace root.
4. Open the integrated terminal and run `git status`—you should see the repo state.
