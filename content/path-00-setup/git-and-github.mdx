## Why

Pipelines and datasets are versioned like code. Git is how teams collaborate without overwriting each other—and how you **prove** what you built.

## Concept

- **Repository** — project folder + history.
- **Commit** — saved snapshot with a message.
- **Branch** — parallel line of work (features, fixes).
- **Pull request** — propose merging your branch; standard in open source and at work.

## Do

1. Create a GitHub account if you do not have one.
2. Configure Git locally (name and email)—never commit secrets.
3. In your learning repo: `git init`, add README, `git commit -m "Start DE101 journey"`.
4. Create an empty GitHub repo and push (HTTPS or SSH).
