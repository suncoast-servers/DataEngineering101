## Why

You cannot learn pipelines without running databases and object storage. Docker lets everyone run the **same stack** without manual installs.

## Concept

- **Image** — blueprint for a service (Postgres, MinIO).
- **Container** — running instance of an image.
- **Compose** — YAML file that starts multiple services together.

## Do

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows/Mac) or Docker Engine on Linux.
2. From the repo root:

```bash
cd labs/compose/core
cp .env.example .env
docker compose --profile core up -d
docker compose ps
```

3. Postgres: host `localhost`, port `5432`, user/db from `.env.example`.
4. MinIO console: `http://localhost:9001` (credentials in `.env.example`).
